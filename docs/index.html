Settings

To save progress from this device, add a GitHub personal access token scoped only to this repository (Contents: Read and write). Without a token you can still browse progress read-only.

  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → Actuarial_Study
  3. Permissions → Repository permissions → Contents → Read and write
  4. Generate token, paste it below

The token is stored only in this browser's local storage and is sent directly to api.github.com when you tick a module. It is never sent anywhere else.
