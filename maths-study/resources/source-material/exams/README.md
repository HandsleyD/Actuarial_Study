# Exam-Specific Source Material

Create one folder per exam code and keep an `index.md` inside it.

Example:

```text
exams/
└── CB2/
    ├── index.md
    ├── textbook-ch01.md
    ├── formula-sheet.md
    └── glossary.md
```

The index should describe which files are most useful for which modules or topics.
